# UI/UX interface для VoiceApp

## Концепція

Kesto — альтернатива Discord/TeamSpeak: оптимізований і швидкий голосовий чат між людьми з можливістю розмовляти, дзвонити та показувати екран. На відміну від TeamSpeak (community servers), базовий фокус — **Direct Call** і **Group Call** без обов'язкових постійних серверів. У майбутньому планується монетизація (premium-підписка), тому UI має залишати місце під non-intrusive upsell-поверхні, не заважаючи ядру продукту.

**Ключова цінність**: подзвонити другу або групі за один клік, з мінімальною затримкою і без зайвого налаштування — і за потреби миттєво показати екран.

## Цільова аудиторія

Спільноти, компанії друзів і невеликі команди, які зараз користуються Discord/TeamSpeak для голосового спілкування, але хочуть швидший і простіший інструмент без обов'язкової прив'язки до "серверів".

## Інформаційна архітектура

- **Друзі / Контакти** — список контактів зі статусом (онлайн, у дзвінку, офлайн), пошук, додавання нових.
- **Групи** — збережені групи контактів для повторних групових дзвінків (аналог "команд" без важкості community-серверів).
- **Активний дзвінок** — головний екран під час розмови: учасники, керування звуком, шеринг екрана.
- **Вхідний дзвінок** — повноекранний overlay для прийому/відхилення.
- **Текстовий чат (з крутими анімаціями вводу)** — якісний чат який зберігає усю історію ...
- **Налаштування** — аудіо/відео пристрої, сповіщення, акаунт, 

## Ключові екрани

1. **Онбординг (2-3 екрани)**
  - Цінність продукту: "дзвони миттєво, без серверів".
  - Дозволи: мікрофон, (опційно) камера/захоплення екрана, сповіщення.
  - Імпорт/додавання перших контактів.

2. **Друзі / Контакти**
  - Список контактів зі статусом присутності (online / у дзвінку / offline) та аватаром.
  - Швидка дія на картці контакту: кнопка дзвінка (одна дія — клік на іконку слухавки).
  - Верхня панель: пошук, вкладки "Друзі" / "Групи".
  - Порожній стан: заклик додати перших друзів.

3. **Групи**
  - Список збережених груп (назва, учасники, іконка).
  - Кнопка "Створити групу" → вибір контактів → назва групи.
  - Клік на групу → одна дія "Почати груповий дзвінок".

4. **Вхідний дзвінок (overlay)**
  - Повноекранне вікно поверх будь-якого контенту застосунку та поверх інших вікон системи (системне сповіщення, якщо застосунок у фоні).
  - Ім'я/аватар того, хто дзвонить (або список учасників для групового дзвінка).
  - Дві великі кнопки: прийняти (зелена) / відхилити (червона), з клавіатурними шорткатами як альтернатива.

5. **Активний дзвінок**
  - Сітка/список тайлів учасників: аватар + індикатор, хто зараз говорить (пульсуюча обводка), індикатор muted.
  - Нижня панель керування: mute мікрофона, deafen (вимкнути звук вхідний), шерити екран, додати учасника, завершити дзвінок (найпомітніша, червона).
  - Таймер тривалості дзвінка, індикатор якості з'єднання (слабкий/стабільний сигнал).
  - Якщо активний шеринг екрана — він займає основний простір, тайли учасників згортаються у смужку зверху/збоку.

6. **Перегляд шерингу екрана**
  - Повноекранний перегляд трансляції з fit-to-window масштабуванням, скрол/zoom колесом миші за потреби.
  - Плаваючі контроли дзвінка залишаються доступними поверх (auto-hide через кілька секунд бездіяльності).
  - Індикатор "хто показує екран зараз" завжди видимий.

7. **Текстовий чат поруч із дзвінком (легкий)**
  - Висувна панель праворуч під час активного дзвінка.
  - Прості текстові повідомлення, посилання, реакції — без важкого функціоналу тредів/каналів.

8. **Налаштування**
  - Аудіо: вибір мікрофона/динаміків, тест звуку, шумозаглушення (noise suppression) — перемикач.
  - Відео/екран: якість шерингу екрана.
  - Акаунт і підписка: статус преміум, порівняння планів (місце під майбутню монетизацію).
  - Сповіщення: вхідні дзвінки, згадки в чаті.

## Користувацькі потоки

- **Прямий дзвінок (Direct Call)**: Друзі → клік на іконку дзвінка біля контакту → екран очікування відповіді → підключення → активний дзвінок.
- **Груповий дзвінок (Group Call)**: Групи → вибір групи (або "Друзі" → вибір кількох контактів) → "Почати груповий дзвінок" → паралельний виклик усіх учасників → підключення по мірі прийняття.
- **Прийом вхідного дзвінка**: push/in-app overlay → прийняти → миттєвий перехід в активний дзвінок / відхилити → повернення до попереднього екрана.
- **Шеринг екрана під час дзвінка**: активний дзвінок → кнопка "Поділитися екраном" → вибір джерела (весь екран / вікно) → трансляція старт → усі учасники бачать оновлений layout.
- **Створення групи для повторних дзвінків**: Групи → "Створити" → вибір контактів → назва → збереження → доступна для швидкого старту наступного разу.

## Принципи дизайну

- **Один клік до дзвінка** — з будь-якого списку контактів чи груп дзвінок стартує за одну дію, без проміжних форм.
- **Пріоритет голосу і зображення екрана над текстом** — UI активного дзвінка не перевантажений вторинними елементами (текстовий чат — прихований за замовчуванням, розкривається за потреби).
- **Миттєвий і зрозумілий фідбек стану з'єднання** — хто говорить, чи стабільний зв'язок, хто в mute — видно без додаткових дій.
- **Некритичне позиціювання монетизації** — преміум-функції та апсейл живуть у Налаштуваннях/окремих банерах, не блокують і не переривають потік дзвінка.
- **Швидкість сприйняття "легше за Discord/TeamSpeak"** — мінімум ієрархії (без обов'язкових серверів/каналів), пласка структура "Друзі → Дзвінок".
- **Доступність** — контраст тексту WCAG AA, повна підтримка керування дзвінком з клавіатури (mute/deafen/end call — гарячі клавіші), читання станів учасників скрінрідерами (говорить/у muted).

## Onboarding flow

**Sign in / Sign up → Welcome message → Короткий tutorial → App**

- **Sign in / Sign up** — перемикач між входом і реєстрацією, поля email/пароль, кнопка "Continue", вторинна опція "Continue with Google".
- **Welcome message** — привітання після реєстрації з ціннісною пропозицією в один рядок і кнопкою "Get started".
- **Короткий tutorial** — 3-кроковий carousel/stepper ("Додай друзів" → "Почни дзвінок в один клік" → "Поділись екраном у будь-який момент") з прогрес-крапками, діями Next/Skip.
- **App** — бокова навігація (Друзі/Групи/Налаштування) + основна панель зі списком друзів.

## Метрики успіху

- Від відкриття застосунку до старту прямого дзвінка — один тап (не рахуючи вибір контакту).
- Учасник дзвінка бачить, хто говорить/у mute, без додаткових дій — стан оновлюється в реальному часі.
- Перехід "почати шерити екран" → перший кадр у інших учасників — відчувається як миттєвий (UI не блокується під час старту трансляції).
- Преміум-поверхні не знижують швидкість базового флоу дзвінка (жодного обов'язкового екрана підписки на шляху до дзвінка).

## Позиціонування і диференціація

Чому платити $7.99 один раз замість безкоштовного Discord/TeamSpeak — без чіткої відповіді жодна метрика доходу не має значення.

**Слабкі аргументи (не використовувати як основні)**
- "Кращий інтерфейс" — недостатньо, щоб подолати звичку користуватись безкоштовним.
- Фіча-паритет із Discord/TeamSpeak — без переваги немає причини платити навіть $1.

**Сильні кути, варті реалізації в продукті (не лише в маркетингу)**

1. **Steam-нативна інтеграція (єдиний справжній moat)** — бачити друзів, які зараз грають у ту саму гру в Steam, дзвонити прямо з Steam overlay без alt-tab, автоматично формувати групу з лобі. Discord/TeamSpeak фізично не мають такого рівня доступу до Steam.
2. **Одноразова оплата проти вічної підписки** — Discord Nitro ($10-12/міс за кращий скрін-шер і звук) назавжди. "$7.99 один раз, назавжди" — сильно, але тільки якщо базова якість реально краща за безкоштовний рівень Discord.
3. **Легкість і швидкість (якщо технічно правда)** — Discord важкий (Electron, багато RAM у фоні). Нативний легкий застосунок, що стартує миттєво — конкретна, перевірювана перевага для геймерів під час гри.
4. **Нуль налаштування (сильніше проти TeamSpeak, ніж проти Discord)** — дзвониш як по телефону, без сервера й адміністрування. У Discord теж є DM-дзвінки без сервера, тому цей аргумент найсильніший саме проти TeamSpeak.
5. **Приватність / без збору даних** — "заплати раз, ми нічого не збираємо, немає реклами" — резонує з невеликою, але лояльною privacy-conscious аудиторією.

**Рекомендація**: обрати 1-2 осі й зробити їх реально відчутними в продукті, не лише в описі на Steam — інакше покупець порівняє з безкоштовним і не побачить причини платити. Найсильніша комбінація: **Steam-інтеграція + легкість/швидкість + одноразова оплата проти підписки**.

**Практичний крок для зниження бар'єру покупки**: випустити безкоштовне demo поруч із платною грою на Steam — знижує ризик "платити не спробувавши", який зараз є найбільшим ризиком конверсії.

## Платформи (вирішено)

Продукт продається на Steam як одноразова покупка — MVP націлений на **desktop**: Windows, macOS, Linux.

- **Steam Deck**: пристрій **не має вбудованого мікрофона** — гравцю знадобиться дротова гарнітура (3.5mm/USB-C) або Bluetooth-гарнітура. UI має коректно обробляти "мікрофон не знайдено" і показувати підказку підключити зовнішній пристрій, а не просто мовчки блокувати дзвінок.
- Steam Deck працює на SteamOS (Linux). Якщо немає нативної Linux-збірки, застосунок піде через Proton (Windows-сумісність) — це варто протестувати окремо на затримку звуку (аудіо в реальному часі чутливе до latency в Proton-шарі), перш ніж заявляти офіційну підтримку Deck.

## Відкриті питання

- Чи потрібна підтримка "постійних кімнат" (аналог voice-channels) у майбутньому, чи Direct/Group Call покриває основний сценарій надовго?
**ВІДПОВІДЬ: Так потрібна буде підтримка постійних кімнат але у майбутньому.**
- Яка модель монетизації планується (якість звуку/відео, кількість учасників у групі, кастомізація) — це вплине на те, де саме показувати premium-точки в UI?
**ВІДПОВІДЬ: Безкоштовний додаток і будуть доступні базові функції ( дзвінок, чат, налаштування, ) і буде можливість підтримати проект та придбати повноцінний застосунок за 7.99 долларів назавжди який буде в себе включати ( Voice Quality, Full HD 1080 screen sharing, high FPS, custom frames, more settings, і ще щось додумаю )**
- Чи потрібна відеокамера (не лише шеринг екрана) як частина базового дзвінка?
**ВІДПОВІДЬ: Відеокамера не потрібна, це голосвий чат для геймерів. ( Шеринг екрану обовязково, 60ФПС FullHD,2K )**
