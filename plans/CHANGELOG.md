# Kesto — Changelog

## 0.1.2 (не опубліковано — потребує збірки на Windows)
- Тимчасовий діагностичний екран "Direct P2P Test" (About → 🔧) — перевірка WebRTC-з'єднання напряму, без участі Steam, щоб зрозуміти чи проблема в Steam-сигналінгу чи в мережі/NAT
- Проактивна ініціалізація Steam relay-мережі при старті (`InitRelayNetworkAccess`) замість очікування до першого дзвінка

## 0.1.1
- **Виправлено критичний краш** при спробі дзвінка на Windows (`ACCESS_VIOLATION`) — головний потік занадто часто звертався до Steam API (кожні 30мс), що конфліктувало з внутрішнім потоком Steam. Знижено частоту до 100мс + кешування повторних викликів `AcceptSessionWithUser`
- Виправлено білий екран при відкритті Messages (старі записи чату без поля назви розмови)
- Додано загальний захисник від подібних крашів (ErrorBoundary) — показує повідомлення про помилку замість порожнього екрану
- Підключено автооновлення (Tauri updater) — після цієї версії наступні оновлення встановлюються самі, без ручного перезавантаження `.exe`

## 0.1.0
- Перша робоча версія: Steam-автентифікація, реальний список друзів, 1:1 дзвінки (WebRTC), текстовий чат (1:1 і груповий), Groups, історія дзвінків, налаштування мікрофону/гучності, три теми (Dark/Light/Glass Liquid)
